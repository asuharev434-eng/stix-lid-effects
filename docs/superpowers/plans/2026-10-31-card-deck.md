# Card Deck Implementation Plan

**Goal:** Add 52 playing cards flying toward the viewer with desktop-fragment backs and reverse restoration.
**Architecture:** Cached card mesh plus vector face atlas, rendered in a dedicated depth-tested Metal pipeline.
**Tech Stack:** Swift, CoreGraphics, CoreText, Metal.

- [x] Test 52 unique card IDs, full desktop coverage and bounded deterministic geometry.
- [x] Draw an original 13-by-4 vector face atlas with ranks and suits.
- [x] Implement 3D rotations, perspective camera passage, rounded card edges and dual face/back sampling.
- [x] Extend GPU endpoint tests and export synthetic card frames for visual inspection.
- [x] Build, sign, install, inspect the selector and validate a close/restore cycle.
- [x] Commit and push GitHub changes, preserving the existing permissions and gestures.
